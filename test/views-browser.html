Every view, rendered

The half of the extension the Node suite cannot reach. rows() is asserted in test/detectors.test.js; this page renders what those descriptions actually turn into, through the real panel.css in a real shadow root — so a class that stopped matching shows up as something you can see. Serve it over http (node tools/static-server.js), because ES modules need an origin.

For dark mode, switch the browser or OS to it and reload. The panel follows prefers-color-scheme, so a control on this page could only restyle the page around it and would tell you nothing about the thing being tested.
