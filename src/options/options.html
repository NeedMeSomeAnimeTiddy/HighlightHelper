Preferences

Amounts like $50 or 30 EUR are converted into this currency.

Measurements already in this system are converted the other way, so the answer is always the one you don't have.

A UK pint is about 20% larger than a US one, so this changes the numbers.

Translations and explanations come back in this language.

Where AI runs

The explain, translate, summarise and rewrite tools need a model. Chrome can run one on this machine — no key, no cost, and the selected text never leaves the computer. Everything else (currency, units, colours, dates, QR codes) is local either way.

Checking…

It is a multi-gigabyte, one-time download, and it needs roughly 22 GB free and a reasonably recent GPU. That's why it is a button rather than something that happens the first time you press a tool.

DeepSeek API key

Needed for the explain, translate, and rewrite tools whenever the on-device model isn't handling them. Currency and unit conversion work without it. Get one at platform.deepseek.com. The key is stored in this browser's local extension storage only — it is never synced to your Google account and never committed to the source.

    My tools

    Your own prompts, each becoming a menu row and a right-click entry. Use {title}, {url} and {lang} for the page's title, its address and your language. The selected text is sent separately — you don't need to mention it, and it is never spliced into your instructions.

      Recent answers

      The last sixty things you asked for, kept in this browser so you can find one again. This is a record of what you highlighted while browsing — it never syncs, and it is one button to clear.

        Highlights

        Everything you have highlighted, grouped by page. Saved in this browser only — no account, no server, nothing synced.

          Search with…

          Which sites the Search with… row offers. Opening one sends the selected text to that site, which is why it is always a button and never automatic.
